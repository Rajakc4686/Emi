# 📊 EMI KCR Tracker

**Singapore 🇸🇬 ↔ India 🇮🇳** | Real-time Family EMI & Income Tracker

## 🎯 What is this?

A web application for couples/families living in different countries to track:
- 💰 **Income** (from Singapore/abroad)
- 🏦 **EMI payments** (in India)
- 📊 **Balance calculation** (Income - EMI)

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **Google Sign-in** | Secure access with your Gmail |
| 📱 **Mobile Friendly** | Works on phone, tablet, laptop |
| ⚡ **Real-time Sync** | Singapore & India see same data instantly |
| 📅 **Date Filter** | Filter records by date range |
| 📎 **Excel Download** | Export to Excel format |
| 📄 **PDF Download** | Export to PDF format |
| 🗑️ **Delete Records** | Remove unwanted entries |

## 🗂️ Tabs

| Tab | Purpose |
|-----|---------|
| 💰 **Income** | Add/view all income records |
| 🏦 **EMI** | Add/view all EMI payments |
| 📊 **Summary** | Combined view + balance calculation |

## 🚀 How to Use

1. **Sign in** with Google account
2. **Add Income** in the Income tab
3. **Add EMI** in the EMI tab
4. **Filter** by date if needed
5. **Download** Excel or PDF reports

## 👨‍👩‍👧 For Families

- Husband (Singapore) adds income
- Wife (India) adds EMI payments
- Both see the same data in real-time
- Balance shows how much is left / deficit

## 🛠️ Tech Stack

- Firebase Realtime Database
- Firebase Authentication (Google)
- HTML5 / CSS3 / JavaScript
- SheetJS (Excel export)
- html2pdf (PDF export)
